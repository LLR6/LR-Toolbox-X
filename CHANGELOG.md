# Changelog

## 0.1.0 — initial development milestone

- 54 portable action handlers with schema validation and common errors.
- 6 native Rust actions, scoped file reads and SQLite history.
- React workbench, command palette, search, favorites, history, themes and language controls.
- Sequential JSON workflows, CLI bundles and generated PWA cache.
- Native Compose Android subset using 6 existing IDs.
- Cross-platform quality, desktop packaging, Android build and CodeQL workflows.

Installers are available only after their CI jobs succeed. No 2000-action, AI or plugin completeness claim.
