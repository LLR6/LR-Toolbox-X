# 六个原生工具逐项说明

以下工具由 Rust 实现，在桌面或原生 CLI 使用，不包含在 134 个便携 Action 中。文件操作需要授予根目录，只能读取该目录内的路径，不能逃逸授权范围；示例输出依实际文件和设备而变。

| 工具 | ID | 输入示例 | 用途与输出 | 限制 |
| --- | --- | --- | --- | --- |
| 文件信息 | `file.info` | `{"path":"README.md"}` | 检查文件类型与字节大小 | 只读，需要文件系统权限 |
| 读取 UTF-8 | `file.read.utf8` | `{"path":"README.md"}` | 读取 UTF-8 文本内容 | 最大 1 MiB；非 UTF-8 文件会失败 |
| 目录列表 | `file.list` | `{"path":"."}` | 查看目录中的条目 | 最多 5000 项，不递归 |
| 文件 SHA-256 | `file.hash.sha256` | `{"path":"README.md"}` | 流式计算文件指纹，用于核对完整性 | 文件最大 1 GiB；哈希相同不证明来源可信 |
| 文件内容比较 | `file.compare` | `{"path":"a.txt","other":"b.txt"}` | 按字节比较两个文件内容 | 每个文件最大 1 GiB；两个路径都须在授权目录内 |
| 系统信息 | `system.info` | `{}` | 查看真实操作系统、CPU 架构和可用逻辑处理器数 | 结果取决于运行设备，不需要文件权限 |

完整工具注册信息与错误处理以 `crates/core/src/lib.rs` 为准。这六项不表示 Android 具备任意文件系统访问能力。
