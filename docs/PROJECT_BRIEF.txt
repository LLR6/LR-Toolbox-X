==================================================
二、最重要原则
==================================================

这个项目绝对不能靠假功能堆数量。

禁止：

- 2000 个空页面
- 2000 个假按钮
- TODO
- Coming Soon
- 点击无反应
- 只有 UI 没 Handler
- 同一个函数复制几十次改名字
- 为了数字机械生成垃圾 Actions
- README 宣传不存在的功能
- 假执行结果
- AI 假装命令执行成功

每个正式计入数量的 Action 必须包含：

- 唯一 ID
- 名称
- 描述
- 分类
- 输入 Schema
- 输出 Schema
- 平台支持
- 权限需求
- Risk Level
- 实际 Handler
- 参数验证
- 错误处理
- 使用示例
- 至少基础测试

例如：

network.dns.a_lookup

network.dns.aaaa_lookup

network.dns.mx_lookup

network.dns.txt_lookup

network.dns.ns_lookup

network.dns.reverse_lookup

这些可以独立算 Action。

因为：

输入/输出/用途不同。

但不能通过复制完全相同的 Handler 冒充多个能力。
