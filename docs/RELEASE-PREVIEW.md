# LR Toolbox X · 任务工作台预览版

本次提供由同一源码提交的成功 CI 构建收集的真实安装包。附件包含 Windows EXE/MSI、Android APK，以及构建通过的其他平台产物和 SHA-256 校验文件。

- Windows：桌面工作台，需要系统 WebView2。尚未进行用户设备安装验收，无商业代码签名，系统可能提示未知发布者。
- Android：开发签名 APK，应用内版本 0.8.0，是较小的 12 项原生工具子集；不包含完整 Web、Ollama 和本地部署中心。不是应用商店生产签名版本。
- 本地 Python 服务：不是 EXE 内自动安装的系统服务。Ollama 与第三方工具仍按文档单独部署，不保证所有平台零交互安装。
- Web：134 个便携 Action、25 个特色入口（含桌面配套入口）。

完整工具逐项说明：docs/TOOLS.md。接入状态：docs/LOCAL-INTEGRATIONS.md。模型、数据源与第三方程序遵守各自许可证。此版本为预览，不将 CI 编译成功等同于真机端到端验收。
